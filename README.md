# Uncommon Programming Languages
## What is this?
Uncommon Programming Languages is a series of in-person and possibly virtual workshops hosted by IEEE-CS@UCF  
Each workshop highlights in some way a programming language that is outside the large zeitgeist of software development to educate our members to new tools 
that might be useful for their careers and projects. This is a place to hold the information that was given out in these events for current and post refrence.  
  
> [!IMPORTANT] 
> These are designed for our members only and so we will not be doing ongoing maintenance of this outside of their needs

## Format of Each Workshop (here)
Each workshop will sit in it's own folder with relavent information as can be reasonably given  
Expect a presenter name, date of presentation (in MM/DD/YYYY), and some helpful notes within a README
