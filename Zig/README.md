## Additional Information
I would highly reccomend using the [Zig Language Refrence](https://ziglang.org/documentation/0.16.0/) and the [Zig Standard Library](https://ziglang.org/documentation/0.16.0/std/) documentation. The language refrence is almost always 
comprehensive so use it as a northern star; as for the std library, more often than not a close reading of the actual code is required, but it will teach idomatic Zig. I always keep one tab of both open when programming, more when I was 
more in the "learning mode". External docs are likely inaccurate due to the velocity of change, but the compiler will point you in the way to improvement.  
You may also want to consider [Ziglings](https://codeberg.org/ziglings/exercises) as a step by step, concept by concept way to learn Zig fundamentals.  
Most Zig projects have moved to Codeberg, so if you're looking for example projects, look there!

### FizzBuzz
FizzBuzz is a well known introductory program for a developer to demonstrate funamental skills in a language. This one is pretty bare bones, but is suitable to solve the problem, consider how you might improve this solution just with 
what is given in the language refrence.
To run this example, run `zig run fizzbuzz.zig`
